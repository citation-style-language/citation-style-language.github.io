## Authors and Publishers

If you are a user of CSL-based software (such as Zotero, Mendeley, or Papers) and need support with the use of CSL styles, please use the support channel of your software product.

To request a new CSL style or report style errors, see [Requesting Styles](/authors/#requesting-new-styles).

## Developers

To discuss CSL development, use our [discussion forum](https://discourse.citationstyles.org/) or the issue trackers of the [relevant GitHub repositories](https://github.com/citation-style-language/).

For feature requests, you can also check the [Zotero forums](https://forums.zotero.org/), where many missing CSL features already have existing discussions.
